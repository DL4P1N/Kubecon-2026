# Security policy

## Supported version

Only `main` is supported. The live demo is `https://conference-companion.ecan.pro`.

## Report a vulnerability

Use GitHub private vulnerability reporting: open the Security tab and select "Report a vulnerability".

If that is not available, open an issue that asks for a private contact. Do not put details in the issue.

## Testing rules

Do not test against the live demo with automated scanners or high request rates.
